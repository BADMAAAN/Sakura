# Controls

Энкодер: вправо — следующий пункт, влево — предыдущий, нажатие — выбор. Back возвращает из инструмента. В обычных меню виден один активный пункт; рабочие результаты и файлы могут быть списками.

На T-Embed CC1101 удержание Back запускает отсчёт Deep Sleep. Back вместе с нажатым энкодером выбирает Restart. Отпустите до завершения для отмены; ориентируйтесь на отсчёт экрана.

Из Display Off/soft Sleep первый input пробуждает экран и поглощается. Для нового действия отпустите кнопку. Deep Sleep пробуждается Back/GPIO6 и проходит загрузку заново.

Подробности, Favorites и startup app: [docs/CONTROLS](../docs/CONTROLS.md). Энергорежимы: [Power Management](Power-Management.md).
