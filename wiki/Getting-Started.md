# Первое знакомство

1. Убедитесь, что плата — T-Embed CC1101 Plus, а установленный образ и его hash известны. Для обновления сначала прочитайте [Installation](Installation.md).
2. На Home поверните энкодер для выбора категории, нажмите для открытия, используйте Back для возврата.
3. В Settings → Sakura Appearance выберите NIGHT/Dawn/Monochrome; Reduced Motion уменьшает декор.
4. Проверьте Home и несколько вложенных меню без запуска активных радиоопераций. Сверьте положение батареи и отсутствие старых пикселей.
5. Если нужен BTC receive, откройте Tools → QRCodes → My BTC Wallet → Set BTC Address. Пока адрес пуст, QR не показывается.

Для [software Sleep и Deep Sleep](Power-Management.md) есть разные сценарии пробуждения. После wake отпустите кнопку перед следующим действием.

При ошибке storage не форматируйте разделы. Сохраните лог и откройте [Troubleshooting](Troubleshooting.md). Полный обзор: [SAKURA_OVERVIEW](../docs/SAKURA_OVERVIEW.md).
