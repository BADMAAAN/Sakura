# Wi-Fi

Раздел использует прежний [WifiMenu](../src/core/menu_items/WifiMenu.cpp): подключение STA, Start WiFi AP, Turn Off WiFi, AP info и инструменты согласно build flags. Для обычного подключения выберите Connect to Wifi и следуйте диалогам сети.

В SAKURA меню категорий показывает один активный пункт. Результаты сканирования, параметры и графики сохраняют собственные данные; оформление не меняет смысл обработчика.

[SSH Profiles](../docs/SSH_PROFILES.md) позволяет создать, изменить, удалить и закрепить профиль. Карточка открывается без соединения; Connect выбирается отдельно, ключ сервера проверяется. Пароль не сохраняется. SSH Macros и новый Web Companion остаются в [roadmap](Roadmap.md). При переключении сетевых инструментов WebUI может завершаться по прежней логике.

При проверке внешнего вида не требуется запускать Wifi Atks, portal или другие активные сценарии. Для диагностики укажите экран, сетевой режим и шаги; исключите пароли/личные SSID из публичного лога. [Список возможностей](../docs/FEATURES.md).
