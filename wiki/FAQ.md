# FAQ

**Почему target и конфигурация называются FLUX/DELTA?** Это совместимые внутренние имена. Продукт называется SAKURA, версия 0.3.1-back; `/flux.conf` и NVS appearance сохранены.

**Это новый код с нуля?** Нет. Это редакция FLUX DELTA на основе FLUX/Bruce. [Лицензии и авторство](../docs/CREDITS.md) сохранены.

**Где адрес BTC?** По умолчанию пуст. Вводите только свой публичный mainnet адрес `1…`/`3…`; `bc1…` в этой версии не поддерживается. Приватные ключи не нужны.

**60 FPS и зелёные вспышки уже проверены?** Такие заявления допустимы только с аппаратным отчётом конкретного образа. Host-preview не измеряет ST7789.

**Ambient Clock экономит как Deep Sleep?** Нет, это работающее приложение.

**Можно очистить flash при ошибке FS?** Это уничтожает данные и не входит в обычное обновление. Сначала backup и [диагностика](Troubleshooting.md).

**Где GitHub Sakura?** Целевой репозиторий — [BADMAAAN/Sakura](https://github.com/BADMAAAN/Sakura). Состав подготовлен локально; первый push и release требуют отдельного подтверждения.
