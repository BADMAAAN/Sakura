# Roadmap SAKURA

Статус описывает состояние кода, а не обещание срока или аппаратной приёмки.

- **IMPLEMENTED** — есть работающий путь в исходниках; конкретные результаты проверок указываются отдельно.
- **EXPERIMENTAL** — есть ограниченная основа/прототип, но требуется проверка или развитие.
- **PLANNED** — функция не реализована как заявленная возможность SAKURA.

Первоочередная работа: физическая проверка цвета/переходов, батареи после зарядки, сна и читаемости QR. Остальной roadmap не реализуется автоматически в рамках исправления этих дефектов.

## Тестирование

| Направление | Статус | Текущая граница / следующий шаг |
|---|---|---|
| Sakura Test Lab | EXPERIMENTAL | Есть host fixtures/preview; собрать воспроизводимую матрицу квалификации |
| Hardware-in-the-Loop | PLANNED | Автоматизированный стенд с реальной платой |
| Fault Injection | EXPERIMENTAL | Есть проверки отказа хранилища/невалидных чтений; систематически расширить случаи |
| Record / Replay | PLANNED | Запись ввода и повторение на host/устройстве |
| UI Golden Tests | PLANNED | Существующие renderer fixtures не заменяют принятый набор эталонов всех экранов |
| Fuzzing | PLANNED | Ограниченные генеративные проверки парсеров и конфигурации |
| Performance Benchmarks | EXPERIMENTAL | Host/device диагностика есть; нужны сопоставимые p95/p99 и реальные LCD/input данные |
| Soak Tests | PLANNED | Длительные прогоны памяти, навигации и sleep/wake |
| Release Qualification | PLANNED | Полный протокол физической приёмки для каждого release hash |

Новые направления добавляются после измерений и конкретной пользовательской задачи. Сначала — сохранение данных и исправление существующего поведения, затем — удобство и расширение функций.

## Согласованные следующие этапы

Пакет Favorites/пять недавних/SSH Profiles/My QR реализован после безопасного аппаратного подтверждения Back. Результаты и границы приёмки перечислены в [отчёте пакета](FEATURE_PACKAGE.md). Следующие десять направлений здесь только планируются; сроки не выдумываются.

| Направление | Статус / сложность | Зависимости | Критерий завершения |
|---|---|---|---|
| SSH Macros | PLANNED / средняя | Профили, проверка server key, отмена | Только явный запуск; изменяющие команды требуют подтверждения; cancel/error tests |
| Local Remote / Web Companion | PLANNED / высокая | Штатный WebUI, единая навигация и владение операциями | Локальный клиент открывает безопасные экраны; активное действие отдельно подтверждается; физический Back приоритетен |
| Фоны с SD | PLANNED / средняя | SD, существующий renderer, проверка формата/памяти | Смена без пересборки; повреждённый файл сохраняет рабочую Sakura; сравнение RAM/кадра |
| Backup/Restore и снимки | PLANNED / высокая | Схема настроек, атомарная запись, версия формата | Preview состава, проверка целостности, восстановление после прерывания без форматирования |
| System Monitor / журнал ошибок | EXPERIMENTAL / средняя | Существующая memory telemetry, bounded log | Экран по запросу; журнал без секретов; измеренный расход памяти и отсутствие фоновой нагрузки |
| Пользовательская IR/RF-библиотека | EXPERIMENTAL / средняя | Существующие файлы, SD, стабильные ID | Просмотр/редактирование/удаление; открытие записи не передаёт сигнал; проверки заглушками |
| Безопасные Scenes | PLANNED / высокая | Профили, явные действия, cancel | Preview шагов, подтверждение изменений, остановка без следующего шага и без скрытой передачи |
| Sakura Test Lab / HIL | PLANNED / высокая | Host backend, device trace, безопасные fixtures | Повторяемый ввод, scan-cancel race, heap/task baseline; отчёты разделяют host и LilyGO |
| Профили питания | EXPERIMENTAL / высокая | Существующий sleep, достоверная батарея, измеритель тока | Проверенные wake/данные и реальный ток каждого профиля; старые жесты сохранены |
| Tamagotchi (опционально) | PLANNED / средняя | Добровольное включение, свободная RAM и idle budget | Выключен по умолчанию; не влияет на Back, батарею и навигацию; memory/response regression PASS |
