# Известные проблемы и границы проверки

Текущий пакет сохраняет прежнюю сцену, данные и набор инструментов. Результаты установленной 0.3.1 приведены в [текущем отчёте](BACK_FOLLOWUP.md); пакет 0.3.0 — в [FEATURE_PACKAGE](FEATURE_PACKAGE.md), прежний hotfix — в [BACK_HOTFIX](BACK_HOTFIX.md).

- Аппаратно подтверждён Back в BLE Spam mode/config без Start и повторный вход новым нажатием. Это не подтверждение всех активных BLE-инструментов.
- На 0.3.0 пользователь ранее подтвердил открытие и Back в Recent screens, SSH Profiles и QRCodes без Connect/Start и создания данных. Подключение к SSH и показ сохранённого QR этим сценарием не проверялись; у 0.3.1 отдельно проверена загрузка.
- Контроллеру может потребоваться время на завершение операции после Cancelling. UI обязан оставаться на экране остановки до фактического завершения; универсальная задержка Back в миллисекундах не измерена.
- Полная отмена унаследованных активных BLE Suite/Ninebot/HID ещё требует доработки и квалификации. Общие Wi-Fi connect/scan и Suite owned-client cleanup исправлены в [0.3.1](BACK_FOLLOWUP.md) и проверены на инертном backend; физическая остановка радио отдельно не проверена. Прямые scan-пути других Wi-Fi инструментов не охвачены этой правкой. Активные радиооперации при проверке UI не запускались.
- Неисправный RapidConnection, терявший владельца characteristic перед записью, явно недоступен. Остались синхронные GATT/HFP вызовы, задержки Ninebot и отдельный HID-server cleanup; исправление Suite registry и его обычного cleanup не закрывает эти самостоятельные пути.
- В установленной libssh 0.11 исключительный путь socket close может оставить внутренний FD неинвалидированным. Обычный caller-owned FD освобождается исправленным путём; библиотечный аварийный путь оставлен в development backlog. Реальный SSH-сервер для проверки подключения не предоставлен.
- QR поддерживает до 154 байт UTF-8, не 154 произвольных символа. Длинные данные отклоняются. Программное декодирование не заменяет чтение QR камерой на LilyGO.
- BTC-профиль пуст, пока владелец не введёт адрес. Поддерживаются только mainnet Base58Check P2PKH/P2SH (`1…`, `3…`); Bech32, testnet и BIP21 не поддерживаются.
- Исторический интервал 1,996 секунды связывал последний encoder sample со следующим DELTA present, без однозначного screen/action/wake контекста. Это не измеренная задержка обычной кнопки и не время сканирования.
- Разовые heap snapshots не доказывают отсутствие утечек. Длительные open/close, task/callback counts, sleep current, полный радио-регресс и зарядный цикл отдельно не квалифицированы.
- История локального Git содержит девять старых generated build logs. Их нельзя удалить из отправляемой истории обычным deletion commit. Для рассмотрения подготовлен отдельный чистый состав публикации с provenance; существующая история не переписывается. Push/release требуют отдельного подтверждения владельца.
