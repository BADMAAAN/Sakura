# Диагностика

| Симптом | Что проверить |
|---|---|
| Зелёная вспышка / неверные цвета | Точную ревизию и hash образа, RGB565, byte swap, RGB/BGR и inversion; отдельно чёрный/белый/RGB pattern, полный кадр и переход sleep/wake |
| Батарея красная после зарядки | SOC, напряжение, BatteryStatus/OperationStatus и charger status, успех I2C; неизвестное чтение не заменять произвольным процентом |
| Батарея смещается | Home, вложенный список и legacy status path на одной ориентации; приложить снимки с названием экрана |
| Нет изображения после wake | Release кнопки, backlight, panelSleep(false), завершение полного deltaUiRestore; проверить логи и память |
| Нажатие сразу открывает приложение | Отпустить wake-кнопку и нажать заново; записать режим сна и точную последовательность |
| Медленное меню | Reduced Motion, Petals, Quality; затем frame/input measurements на устройстве |
| Нет BTC QR | Адрес ещё пустой/невалидный; поддерживаются mainnet Base58Check 1/3, не bc1 и не URI |
| BTC адрес не сохранился | Доступность хранилища и сообщения записи; перезапуск и повторное чтение настройки |
| LittleFS не монтируется | Сохранить boot log и таблицу разделов; загрузка должна продолжиться без форматирования |
| Не компилируется | Верный target flux-delta, Python/PlatformIO, pinned packages, Pillow; отсутствие параллельного build |
| COM занят | Завершить monitor/другую программу, проверить порт; один процесс управления устройством |

Host-preview позволяет повторить меню и геометрию; он не тестирует LCD transfer и питание. Не маскируйте зелёные артефакты другой темой без проверки пути передачи цвета. В устройстве могут оставаться специальные legacy-экраны с собственным renderer.

В bug report укажите версию, commit/hash приложения, плату, питание USB/батарея, ориентацию, экран и шаги воспроизведения; приложите обезличенный лог и фото дисплея. Не публикуйте `flux.conf`, Wi-Fi данные, private dump или личный BTC адрес.

При ошибках хранилища не используйте factory reset/erase/format как первое действие. Резервный дамп храните отдельно. См. [установку](INSTALLATION.md), [питание](BATTERY_AND_SLEEP.md) и [сборку](BUILDING.md).
