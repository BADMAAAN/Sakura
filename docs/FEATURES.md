# Возможности и границы

IMPLEMENTED означает наличие кода. Сборка и физическая проверка конкретного модуля — отдельные результаты.

| Раздел | Что сохранено / добавлено |
|---|---|
| Home, Settings, Favorites | Сцена сакуры и одиночный выбор сохранены; 24 избранных по ID, порядок, пять недавних в RAM, безопасные SSH/QR ссылки |
| SSH Profiles | 12 профилей name/host/port/user; пароль только в RAM; явный Connect, server key, таймауты и отмена |
| Wi-Fi | Подключение STA/AP, информация сети, сетевые инструменты и унаследованный WebUI |
| BLE | Сканирование, BLE Suite, HID и другие обработчики исходного проекта, согласно build flags |
| RF | CC1101, scan/copy, RAW, spectrum и работа с файлами сигналов |
| RFID | PN532 и унаследованные операции с метками, зависящие от выбранного модуля |
| IR | TV-B-Gone, Custom IR, чтение ИК и настройки пинов |
| Files / Scripts | Работа с SD/LittleFS и JavaScript interpreter, если он включён |
| QR Codes | Название/текст, просмотр/изменение/удаление/Favorites; точное кодирование до 154 байт; отдельный пустой BTC receive профиль mainnet 1/3 |
| Clock / Tools | Унаследованные часы, микрофон и другие доступные в сборке приложения |
| Питание | Dim, Display Off, software Sleep и явный Deep Sleep; проверка достоверности SOC |

LoRa, Ethernet, GPS, NRF24 и другие пункты исходного дерева могут требовать отдельный модуль, проводку и настройку. Наличие пункта или исходника не означает встроенное оборудование и проверенную совместимость. Полный унаследованный набор описан в [исторической карте функций](FLUX-DELTA-FUNCTIONS.md), с учётом её ревизии.

Визуальная редакция не переизобретает сетевые протоколы и драйверы. Она использует их прежние entry points. Полная регрессия активных радиоопераций не следует из успешного host render.

SSH Profiles входит в первый пакет; реальный сервер ещё не квалифицирован. SSH Macros, Workspaces, BLE Companion и Safe Update Manager остаются в [ROADMAP](ROADMAP.md). Используйте инструменты только в разрешённой среде.
