# Архив конфигурации upstream

Унаследованные GitHub Actions и FUNDING сохранены здесь с исходными credits, но не активны в SAKURA. Они нацелены на набор плат и публикацию Bruce, могут создавать релизы и загружать бинарные файлы. Первый push SAKURA публикует исходники и документацию без запуска этих workflows. Автоматическая сборка SAKURA и релизы требуют отдельной настройки и проверки.

Inherited workflows and funding are preserved with their credits, outside the active GitHub configuration. They target upstream boards and releases; Sakura CI and releases are not configured or claimed.
