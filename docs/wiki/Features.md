# Features

FLUX provides a menu-driven interface for the capabilities supported by the
T-Embed CC1101 Plus hardware and its attached peripherals:

- Wi-Fi tools
- BLE tools
- Sub-GHz RF through CC1101
- LoRa
- RFID
- IR
- Device and UI customization

Availability can depend on hardware revision, attached accessories and the
selected build environment. Use these functions only with authorization.
