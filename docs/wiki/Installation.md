# Installation

## Hardware

This project targets the LILYGO T-Embed CC1101 Plus. Connect the device with a
known-good USB data cable and identify its serial port before flashing.

## Firmware

Build the firmware from source using the instructions in [Building from Source](Building-from-Source.md).
Do not erase a device containing an existing installation unless you have a
verified full-flash backup and have explicitly decided to replace it.

The first public release is not declared by this source publication. A release
binary will be provided only after physical validation.
