# Project Structure

- `src/` — firmware implementation and feature modules
- `include/` — shared headers and UI interfaces
- `boards/` — board definitions and flash layouts
- `lib/` — vendored and project libraries
- `embedded_resources/` — web and embedded resources
- `sd_files/` — files intended for the device SD card
- `tests/` — project and UI regression tests
- `scripts/` — build and resource tooling
- `docs/` — design notes, build notes and wiki source pages
- `assets/` — public project artwork

Private working directories, device backups, AI state, logs and `.pio/` build
outputs are intentionally excluded from publication.
