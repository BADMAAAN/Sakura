# Changelog SAKURA

## 0.3.1-back — локальная доработка, 2026-10-16

- Общие Wi-Fi connect/scan: явные Cancelled/Busy, отмена без следующей сети, Retry, AP или WebUI; guard фоновой операции, сохранение чужого AP/STA/WebUI и проверка остановки своей STA.
- Suite: registry без дубликатов, owned disconnect/NONE/host-fence перед delete, правдивый отказ cleanup и ожидание освобождения до выхода/нового запуска; общий BLE host сохраняется.
- Неисправный RapidConnection явно недоступен до исправления владения characteristic. Полный P0 GATT/HFP/HID остаётся открытым.
- WireGuard закреплён на уже использованном commit после обнаруженного resolver drift; новые зависимости не добавлены.
- Проверки и ограничения: [доработка Back](BACK_FOLLOWUP.md).

## 0.3.0-sakura — первый пакет, 2026-10-16

- Favorites по устойчивым ID: разделы, безопасные экраны, SSH-профили и свои QR; изменение порядка/удаление, без новых панелей Home.
- Recent: пять разных безопасных экранов только в RAM; очистка, отключение, без содержимого профилей/QR и записей на каждое движение.
- SSH Profiles: name/host/port/user, явный Connect, пароль только в RAM, проверка server key, таймауты и отмена; обработка partial writes и обычное освобождение socket.
- My QR: название/текст/ссылка, просмотр/изменение/удаление/Favorites, устойчивые ID; настоящий генератор и точное декодирование до 154 байт UTF-8, без обрезки.
- Одобренный интерфейс, пустой BTC-профиль, данные и текущая разметка сохранены. Следующие функции остаются в roadmap.
- Проверки, установка и открытые ограничения: [отчёт пакета](FEATURE_PACKAGE.md).

## 0.2.1-back — 2026-10-16

Исправление маршрутизации Back/Select, stable press/release, кооперативная отмена scan и Buttons Diagnostics. Отдельный бинарный файл и source archive сохранены. Пользователь подтвердил возврат и новый вход в безопасном BLE Spam config без Start. Подробности: [Back hotfix](BACK_HOTFIX.md).

## 0.2.0-sakura — 2026-10-16, кандидат исходников

- Пользовательский бренд SAKURA / SAKURA NIGHT; внутренний target flux-delta и совместимые данные сохранены.
- Основные меню возвращены к single-focus представлению; существующая сцена сакуры сохранена.
- Чёрно-розовая палитра, общий статус батареи и проверка переходов цвета/рендера.
- Fuel gauge проверяет готовность INITCOMP и исключает configuration/calibration state; ложные startup значения не становятся реальным SOC.
- Подсветка гаснет до deep-sleep shutdown; software wake передаёт полный кадр до включения подсветки; wake input не используется как Select.
- My BTC Wallet: публичный адрес mainnet P2PKH/P2SH с Base58Check; пустой по умолчанию; QR с белым quiet zone.
- Подготовлены русские руководства, Wiki и roadmap со статусами.

Этот список описывает изменения исходников. Итоговая сборка, hash, аппаратные измерения, установка и физическая приёмка должны фиксироваться в отдельном отчёте конкретного образа. Он не объявляет достигнутыми 60 FPS или полное отсутствие артефактов на физическом экране.

История FLUX/DELTA сохранена в Git, [прежнем README](FLUX_README.md) и [материалах DELTA](FLUX-DELTA.md); её даты и результаты не переносятся автоматически на SAKURA.
