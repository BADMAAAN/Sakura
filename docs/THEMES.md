# Темы и Sakura Appearance

Откройте **Settings → Sakura Appearance**. Доступны SAKURA NIGHT, Sakura Dawn и Monochrome. Основная редакция NIGHT использует глубокий чёрный фон и розовые акценты; дерево и композиция взяты из уже существующей сцены DELTA.

| Настройка | Значения / назначение |
|---|---|
| Theme | SAKURA NIGHT / Sakura Dawn / Monochrome |
| Quality | Low / Normal / High |
| Petals | Off / Low / Normal / High |
| Transition | 140 / 160 / 180 мс |
| Subtle Glitch | Декоративный эффект On / Off |
| Reduced Motion | Ограничивает движение и переходы |
| Status / Icons | Показывать строку статуса / иконки |
| Brightness | Штатная яркость экрана |
| Favorites | Выбор избранных категорий |
| Ambient Clock | Часы на включённом экране; это не режим сна |

Если управление кажется тяжёлым, сначала включите Reduced Motion или уменьшите лепестки. Эти настройки меняют декор, а не назначение кнопок и радиообработчиков.

Если измеренное время кадра превышает бюджет на 2 мс, Home на секунду снижает лепестки до Low и отключает glitch. Выключенные лепестки остаются выключенными; сохранённые настройки не меняются.

Небольшая запись appearance хранится в NVS `flux_delta`, ключ `appearance`, с версией и checksum. Старые версии декодируются в памяти, неизвестные/повреждённые записи используют defaults без записи на загрузке. Сохранение происходит при явном изменении настройки. Имена namespace и enum сохранены для совместимости; они не означают старый пользовательский бренд.

Исходники: [delta_ui.cpp](../src/core/delta_ui.cpp), [settings.h](../include/delta/settings.h), [renderer](../include/delta/core.h). Старые скриншоты не гарантируют внешний вид этой ревизии; фактический ST7789 проверяется отдельно.
