# FLUX DELTA — проверка внутренних экранов

Текущая доработка продолжает системный UI из `e4ba2cd92ecb7065338665a28d602081c5d8ed81` в отдельном `C:\Projects\FLUX-DELTA`. Старая `C:\Projects\FLUX` не изменяется. Статус поставки и аппаратные результаты приведены ниже; хостовые кадры не считаются подтверждением физического запуска.

Новая application установлена и запущена. Пользователь на LilyGO подтвердил исчезновение чёрного блока BLE, читаемость текста и работу энкодера/Back без следов кадров после проверки Wi-Fi main, BLE Spam Config и Delta Appearance.

## Изменения

- Общие внутренние виджеты используют нативный шрифт с 4-битным сглаживанием: основной 14 px, метаданные 12 px, показания 25 px. Атлас включает ASCII, Latin-1 и кириллицу; прочие codepoint отображаются одним `?`. Домашний экран сохраняет прежнюю художественную отрисовку.
- BLE Spam list/config больше не выводят непрозрачный чёрный sprite поверх темы. DELTA-ветка рисует фон, строки, значения и подсказки на общем framebuffer. Передачи и обработчики управления сохраняют прежнюю логику.
- Wi-Fi main занимает весь экран: три крупных строки и боковая зона состояния. Результаты используют RSSI, канал, security и BSSID выбранной сети из существующей модели. Действия навигации не получают вымышленные показания.
- RF сохраняет исходные измеренные массивы, но выводит частоту, крупный peak/RSSI, координаты и график как единый прибор. Отсутствующие отсчёты остаются отсутствующими.
- Общий приглушённый фон Sakura виден за панелями, выбранная строка и открытие стандартных экранов обновляются по времени без блокирующей анимационной очереди. Слоты нижних подписей и UTF-8 хвост клавиатуры исправлены под новые метрики.

## Полная локальная копия

Исходники находятся в `C:\Projects\FLUX-DELTA`. Отдельный `artifacts/FLUX-DELTA-INTERIOR-SOURCES.zip` содержит исходники и графику, preview/tests/docs, 38 публичных библиотек, проверенную application и `validation.json`. Предыдущие архивы сохраняются. Контрольная сумма самого ZIP записывается рядом в `interior-source-archive.json`, без самоссылки.

Для повторения исторического сравнения и двух BLE parity tests нужен commit `e4ba2cd9`. В архив включён `source-history.bundle` с достижимой историей текущей ветки. После распаковки **в отдельную новую папку** восстановите Git metadata, сохранив точные распакованные файлы:

```powershell
git init
git fetch source-history.bundle HEAD
git reset --mixed FETCH_HEAD
```

Это не требуется для просмотра готовых изображений. Компиляторы и Python окружение в исходный ZIP не входят; текущие установленные инструменты и pinned build config сохранены локально. Секреты, приватный flash dump, `.codex`, рабочие checkpoint и toolchain в ZIP не включаются. Push/release не выполнялись.

Активные BLE/RF передачи, атаки, SSH и Deep Sleep автономно не выполняются. Хостовый рендер не измеряет FPS LilyGO, отзывчивость энкодера или ток. Полное покрытие Unicode и проверка всех специализированных терминалов/игр не заявляются.
