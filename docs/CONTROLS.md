# Управление

| Действие | Результат |
|---|---|
| Поворот энкодера по часовой стрелке | Следующий пункт |
| Поворот против часовой стрелки | Предыдущий пункт |
| Нажатие энкодера | Открыть выбранный пункт / подтвердить |
| Кнопка Back | Назад или выход, согласно текущему инструменту |

Начиная с hotfix 0.2.1-back короткая верхняя кнопка (GPIO6) имеет приоритет Back/Cancel; нажатие энкодера (GPIO0) — Select. Удержание не повторяет действие между экранами. Settings → Diagnostics → Buttons показывает физический источник и распознанное событие; Back возвращает в Diagnostics.

Отмена проверенных scan-путей запрашивает stop и возвращается после фактического завершения. Ошибка stop остаётся на экране операции; новый Back повторяет запрос. Для owned-client connect/discoverAttributes добавлено ожидание завершения worker и NimBLE host с экраном Cancelling. Остальные синхронные refresh/read/write и часть активных BLE Suite/Ninebot пока не квалифицированы: подробности находятся в [отчёте пакета](FEATURE_PACKAGE.md).

В 0.3.1 общие Wi-Fi connect/scan передают отмену без Retry/AP/WebUI fallback. Suite cleanup сохраняет чужие подсистемы и ждёт освобождения своих клиентов до выхода или свежего запуска. При ошибке остаётся экран cleanup; новый Back повторяет попытку. [Границы этой правки](BACK_FOLLOWUP.md) не означают отмену всех активных BLE-инструментов.

На Home и в общих меню выбран один крупный пункт. В результатах Wi-Fi/BLE, файлах, параметрах и графиках могут сохраняться списки: они показывают полезные данные инструмента.

Settings → Sakura Appearance управляет темой и анимацией; [Favorites](QUICK_ACCESS.md) открывает закреплённые разделы, безопасные экраны, карточки SSH и сохранённые QR. Recent screens доступен из Favorites и Settings. Название Tools на Home соответствует унаследованному разделу Others, а Settings — Config. Пункт QRCodes находится в Tools; SSH Profiles — в Wi-Fi.

После Display Off первый поворот/нажатие используется для пробуждения и не запускает приложение. После software Sleep кнопка также поглощается до отпускания. Для нового действия отпустите её и нажмите ещё раз.

На T-Embed CC1101 удержание Back показывает отсчёт Deep Sleep; обработчик использует порог 3 секунды после начальной задержки 500 мс и ожидает отпускания. Сочетание Back с нажатым энкодером выбирает отсчёт Restart с порогом 5 секунд. Отпускание до завершения отменяет действие. Уточняйте отображаемый отсчёт; это не сочетание для factory reset.

Пробуждение Deep Sleep — кнопкой Back (GPIO6, штатный EXT0). Загрузка выполняется заново, в отличие от software Sleep. Сохранённое startup-приложение предлагается запустить явно; сам просмотр приглашения не должен запускать его.

Реальные функции кнопок конкретного инструмента могут отличаться. Для первичной проверки внешнего вида достаточно меню; не запускайте RF/IR/BLE передачи ради теста переходов.
